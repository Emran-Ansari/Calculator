# 🧮 Modern Dark Calculator

A clean and simple dark-mode calculator with a beautiful, modern user interface. I designed this project with a minimalist layout and added cool geometric math shapes in the background for a unique look.

## ✨ Features

- **Clean Design:** Minimalist dark mode theme that looks great and is easy on the eyes.
- **Modern UI:** Sleek button layout with smooth hover effects.
- **Easy to Use:** Simple, straightforward, and focused on everyday calculations.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)

## ⚙️ How to Run

1. Clone the project:
   ```bash
   git clone https://github.com/Emran-Ansari/Calculator.git
   ```
2. Open `index.html` directly in your browser.
